# 胰管家·呼吸助手 (PancrePal Breath Assistant)

> 面向江苏省人民医院胰腺专病护理团队的 **胰腺术后肺功能恢复评估小程序** —— 患者对手机吹气，游戏化即时反馈，护士端趋势监测，全程循证医学依据。

## 🎯 一句话定位

**非医疗器械的辅助评估工具**：患者每日"吹气 1 分钟"，小程序通过麦克风采集声学信号，用吹蜡烛等游戏化画面即时反馈，并生成**相对自身的肺功能恢复趋势**，辅助护士评估胰腺术后患者恢复情况。

## 📋 核心文档

- 📄 **[产品需求文档 PRD](./PRD.md)** —— 完整需求、分层算法架构、循证医学依据框架（v0.2 草案，待临床评审）

## 🏥 背景

胰腺外科手术（尤其胰十二指肠切除术）创伤大，术后肺并发症（PPC）发生率高，围手术期护理中肺功能评估与呼吸训练是核心环节。传统肺功能仪/峰流速仪设备门槛高、无法高频随访，护士人力有限，患者依从性差。本项目用**手机麦克风 + 游戏化反馈**解决这一护理痛点。

## 🔬 核心设计

- **分层渐进算法**：MVP 以游戏化 + 相对趋势为主（不做绝对值诊断）；预留声学 PEF/FEV1 估算与临床级评估接口。
- **循证医学依据框架**：所有评估指标、话术、预警阈值可溯源至证据清单（[PMID 索引见 PRD §14](./PRD.md#14-附录证据清单索引可评审)），并设临床专家评审机制。
- **明确边界**：辅助/趋势监测，不输出诊断结论，不做医疗器械。

## 🧱 技术栈（草案）

微信小程序（`RecorderManager` 麦克风帧采集 + Canvas 游戏画面）· Python/Node 后端 · 与社区 `miniapp-xyb` 生态对齐。

## 🔗 可借鉴开源项目

已调研一批**可直接复用/改造**的前置开源技术栈（手机麦克风肺功能评估、GLI-2012 参考值方程、开源肺量计、呼吸动画），详见 **[PRD §7.4 可借鉴的开源技术栈](./PRD.md#74-可借鉴的开源技术栈前置参考)**。
